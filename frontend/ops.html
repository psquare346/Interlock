This console provisions customers. It is gated by the platform operator key (server env OPERATOR_KEY), not a tenant login.

Customers

Each customer is a tenant — a sealed account no other customer can see into. Provisioning creates the tenant, its punchout secret, its PO key, and the first admin's invite in one step. Every credential is shown once; the server stores only hashes. Hand the register link to the customer's admin and the SAP values to their Basis team.
